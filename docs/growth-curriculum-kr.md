# DestinyLab 성장 실행 커리큘럼

이 문서는 `lovecompatibilitycalculator.com`을 월 300만원 수익 목표에 맞춰 키우기 위한 실행 순서다.

## 원칙

- 먼저 좋은 제품처럼 느껴지게 만든다.
- 검색 유입은 콘텐츠 클러스터로 만든다.
- 무료 확산은 결과 공유 카드로 만든다.
- 광고는 유입이 생긴 뒤 최적화한다.
- 유료 리포트는 트래픽과 공유 데이터가 생긴 뒤 실험한다.

## 실행 트랙

### Track A: Product UX

- 홈: 바로 테스트할 이유를 만든다.
- 테스트 페이지: 계산기를 먼저 보여준다.
- 결과 페이지: 한눈에 읽히는 리포트로 만든다.
- 허브 페이지: 사용자가 다음 클릭을 고르게 만든다.

### Track B: Viral Loop

- 공유 카드 1200x630 제작
- 스토리용 1080x1920 제작
- 공유 문구 자동 생성
- Pinterest/X/WhatsApp/SMS 공유 버튼 유지
- 결과 페이지에서 비교 테스트 유도

### Track C: SEO Cluster

- 핵심 테스트 페이지 강화
- 점수 의미 가이드 강화
- zodiac/name/birthday 클러스터 강화
- 내부 링크로 계산기와 가이드 왕복

### Track D: Trust and Monetization

- AdSense 코드, ads.txt, 정책 페이지 유지
- 광고 배치는 승인 후 보수적으로 시작
- 상세 리포트 CTA를 작게 실험
- PDF/프리미엄 해석은 수요 확인 후 개발

### Track E: Marketing

- Pinterest 이미지 업로드
- TikTok/Reels 짧은 스크립트 제작
- Reddit/Quora 답변형 유입
- 소액 광고는 전환 데이터가 생긴 뒤 시작

## 이번 스프린트

1. 공유 카드 디자인 개선
2. 결과 이미지 다운로드 옵션 추가
3. 결과 화면에서 소셜 공유 문구 강화
4. 빌드/린트 검증
5. 배포 후 라이브 확인
