# 월 300만원 목표 성장 커리큘럼

목표는 단순히 페이지를 많이 만드는 것이 아니라, 검색 유입과 공유 유입이 반복되는 구조를 만드는 것이다. 광고 수익은 결과이고, 먼저 만들어야 할 것은 사용자가 테스트하고, 결과를 저장하고, 다른 사람에게 보내는 흐름이다.

## 현실적인 수익 구조

AdSense만으로 월 300만원을 만들려면 트래픽이 꽤 커야 한다. RPM을 보수적으로 3-8달러로 보면 월 30만-75만 페이지뷰가 필요할 수 있다. 초기 사이트가 바로 가기에는 높다.

그래서 더 현실적인 구조는 혼합 모델이다.

- 무료 계산기와 SEO 콘텐츠로 방문자 확보
- 공유 가능한 결과 카드로 무료 유입 확대
- AdSense로 기본 수익화
- 이후 상세 리포트, PDF, 프리미엄 해석으로 객단가 추가

## 8주 실행 커리큘럼

### 1주차: 제품 첫인상

- 홈 첫 화면에서 10초 안에 무엇을 얻는지 보이게 한다.
- 핵심 계산기 페이지는 글보다 도구가 먼저 보이게 한다.
- 폰트, 줄간격, 버튼, 입력폼의 기본 가독성을 정리한다.
- About, Privacy, Cookie, Terms, Disclaimer, Contact를 푸터에서 쉽게 찾게 한다.

성공 기준:

- 홈에서 계산기 진입이 자연스럽다.
- `/calculator`, `/tests`, `/blog`가 완성된 허브처럼 보인다.
- 모바일에서 텍스트가 답답하거나 겹치지 않는다.

### 2주차: 결과 화면과 공유 루프

- 결과 화면에 점수, 해석, 강점, 주의점, 다음 행동을 한눈에 보여준다.
- 공유 카드 이미지를 더 예쁘게 만든다.
- Pinterest, Instagram Story, X, WhatsApp, SMS 공유 흐름을 강화한다.
- "친구에게 보내기 좋은 문장"을 결과 화면에 제공한다.

성공 기준:

- 결과 이미지 다운로드 클릭이 생긴다.
- 공유 버튼 클릭률을 측정할 수 있다.
- 결과 페이지에서 다른 테스트로 넘어가는 클릭이 생긴다.

### 3주차: SEO 핵심 페이지 강화

우선순위 페이지:

- `/calculator`
- `/love-percentage`
- `/name-compatibility`
- `/zodiac-compatibility`
- `/birthday-compatibility`
- `/true-love-test`
- `/couple-test`
- `/tests`
- `/blog`

작업:

- 검색 의도에 맞는 제목과 설명을 정리한다.
- 각 페이지에 점수 해석, 사용 예시, FAQ, 다음 테스트 링크를 넣는다.
- 얇은 문장을 줄이고 실제 행동 조언을 늘린다.

성공 기준:

- Search Console에서 노출이 있는 페이지의 CTR이 오른다.
- 색인된 페이지가 늘어난다.
- 평균 페이지뷰/세션이 증가한다.

### 4주차: 블로그 클러스터

핵심 주제:

- love compatibility score meaning
- low compatibility score meaning
- is love calculator accurate
- next steps after compatibility score
- zodiac compatibility chart
- name compatibility by name

작업:

- 블로그 허브에서 사용자가 읽기 경로를 고르게 한다.
- 글 하단에서 계산기로 돌아오는 CTA를 명확히 한다.
- 결과 화면에서 의미 해설 글로 연결한다.

성공 기준:

- 블로그에서 계산기로 이동하는 클릭이 생긴다.
- 가이드 페이지가 검색 유입을 받기 시작한다.

### 5주차: 소셜/Pinterest 패키지

- 결과 이미지를 1200x630, 1080x1920 두 가지로 만든다.
- Pinterest용 제목 문구를 만든다.
- TikTok/Reels용 짧은 영상 스크립트 20개를 만든다.
- "우리 몇 점 나왔게?" 스타일의 소셜 훅을 만든다.

성공 기준:

- 저장하거나 올리고 싶은 결과 이미지가 생긴다.
- 수동으로 소셜 업로드 테스트가 가능하다.

### 6주차: 신뢰도와 AdSense 안정화

- 광고 스크립트, ads.txt, 정책 페이지를 재확인한다.
- 광고를 과하게 배치하지 않는다.
- 자동 광고가 UX를 해치지 않는지 본다.
- "entertainment and reflection" 문구를 자연스럽게 유지한다.

성공 기준:

- AdSense 검토에 필요한 기본 신호가 명확하다.
- 정책 페이지와 연락처가 정상 작동한다.
- 모바일에서 광고 때문에 핵심 흐름이 막히지 않는다.

### 7주차: 데이터 기반 개선 루프

매주 확인:

- Search Console 노출/클릭/CTR
- 많이 노출되지만 CTR 낮은 페이지
- 계산기 제출 이벤트
- 결과 공유 이벤트
- 이미지 다운로드 이벤트
- 내부 링크 클릭

작업 방식:

1. 노출은 있는데 CTR 낮은 페이지 3개 선택
2. 제목, 설명, 첫 문단, FAQ 개선
3. 내부 링크 보강
4. URL 재색인 요청
5. 7-14일 뒤 변화 확인

### 8주차: 수익 확장 실험

AdSense만으로 부족하면 유료 상품을 작게 실험한다.

후보:

- 상세 커플 리포트
- PDF 다운로드
- 월간 관계 체크인 리포트
- 프리미엄 AI 해석

처음부터 결제 시스템을 크게 만들지 않는다. 먼저 버튼, 랜딩, 대기 리스트로 수요를 확인한다.

## 마케팅 실행 순서

1. SEO: 핵심 페이지와 블로그 클러스터 강화
2. Pinterest: 결과 카드와 가이드 이미지를 꾸준히 업로드
3. TikTok/Reels: 짧은 테스트 결과 훅 영상
4. Reddit/Quora: 질문 답변형 유입
5. 소액 광고: 공유 카드/테스트 페이지로 A/B 테스트

처음부터 큰 광고비를 쓰면 위험하다. 광고는 사이트가 이미 공유/체류/전환을 어느 정도 만들 때 시작하는 편이 낫다.

## 현재 우선순위

1. 공유 이미지 퀄리티 개선
2. 결과 화면의 감정적 보상 강화
3. 핵심 SEO 페이지 문장 밀도 개선
4. Pinterest와 SNS용 콘텐츠 패키지 제작
5. Search Console 기반 주간 개선 루프
